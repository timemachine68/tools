# tools

เครื่องมือเล็ก ๆ ใช้งานส่วนตัว แต่ละตัวเป็นไฟล์ HTML ไฟล์เดียว เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้ง

## heic-to-jpg.html

แปลงรูป HEIC จาก iPhone เป็น JPG เพื่อนำไปโพสต์ลงโซเชียล

- เลือกหรือลากรูปมาวางได้ครั้งละหลายรูป
- เลือกขนาด (ขนาดเดิม / 2048 / 1440 / 1080 พิกเซล) และคุณภาพ (50–100%)
- ดาวน์โหลดทีละรูป หรือทั้งหมดเป็น ZIP
- บนมือถือที่รองรับ มีปุ่ม "แชร์ / บันทึกลงอัลบั้ม"
- แปลงในเครื่อง ไม่อัปโหลดรูปไปไหน และ JPG ที่ได้ไม่มีพิกัด GPS

**วิธีใช้:** ดาวน์โหลดไฟล์แล้วเปิดด้วยเบราว์เซอร์ ต้องต่อเน็ตตอนแปลงครั้งแรก เพราะโหลดตัวแปลง ([heic-to](https://github.com/hoppergee/heic-to)) และตัวสร้าง ZIP ([JSZip](https://stuk.github.io/jszip/)) จาก jsDelivr
