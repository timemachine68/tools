# tools

เครื่องมือเล็ก ๆ ใช้งานส่วนตัว แต่ละตัวเป็นไฟล์ HTML ไฟล์เดียว เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้ง

## heic-to-jpg.html

แปลงรูป HEIC จาก iPhone เป็น JPG เพื่อนำไปโพสต์ลงโซเชียล

- เลือกหรือลากรูปมาวางได้ครั้งละหลายรูป
- เลือกขนาด (ขนาดเดิม / 2048 / 1440 / 1080 พิกเซล) และคุณภาพ (50–100%)
- ดาวน์โหลดทีละรูป หรือทั้งหมดเป็น ZIP
- บนมือถือที่รองรับ มีปุ่ม "แชร์ / บันทึกลงอัลบั้ม"
- แปลงในเครื่อง ไม่อัปโหลดรูปไปไหน และ JPG ที่ได้ไม่มีพิกัด GPS

**วิธีใช้:** ดาวน์โหลดไฟล์แล้วเปิดด้วยเบราว์เซอร์ ต้องต่อเน็ตตอนแปลงครั้งแรก เพราะโหลดตัวแปลง ([heic-to](https://github.com/hoppergee/heic-to)) และตัวสร้าง ZIP ([JSZip](https://stuk.github.io/jszip/)) จาก jsDelivr

## round-hunter.html

เกมควิซชูนิ้ว "นักล่ารอบ TCAS" สำหรับแนะแนว ม.6 ชูนิ้ว 1–4 แทน TCAS รอบ 1–4 ให้กล้องอ่านคำตอบ

- 3 ชุดคำถาม: รอบไหนดี (27 ข้อ) · ทางไปต่อ/แผน B (12 ข้อ) · ผสม (39 ข้อ)
- โหมดศึกแถว (ไฟลุก ชิงตอบ รอบสุดท้าย ×2 ดวลข้อตัดสิน) และโหมดผลัดกันตอบ
- เล่นบนเครื่องครูเครื่องเดียว ไม่ต้องใช้เน็ต ถ้ากล้องใช้ไม่ได้ ครูกดปุ่ม 1–4 แทน
- วันที่ในเกมตรวจจาก mytcas.com เมื่อ 9 พ.ย. 2569 ถ้า mytcas เปลี่ยนกำหนดการ ต้องแก้คำถามในไฟล์

## rumor-check.html

เกม "จริงหรือมั่ว? ข่าวลือ TCAS70" สำหรับแนะแนว ม.6 ดีไซน์กระดาษตัดสีพาสเทลแบบสต็อปโมชัน

- ยกนิ้วโป้งขึ้น = จริง · คว่ำนิ้วโป้งลง = มั่ว ค้างไว้ 1 วินาที กล้องล็อกคำตอบให้
- คลัง 32 ข่าวลือ (จริง 14 · มั่ว 18) เรื่องปฏิทิน ยืนยันสิทธิ์ สละสิทธิ์ ความปลอดภัยของบัญชี และแผน B
- โหมดศึกแถว (ถูกติดกันได้โบนัส รอบสุดท้าย ×2 ดวลข้อตัดสิน) และโหมดผลัดกันตอบ
- ไม่ต้องใช้เน็ต ถ้ากล้องใช้ไม่ได้ ครูกด ↑ (จริง) หรือ ↓ (มั่ว) แทน
- ข้อมูลตรวจจาก mytcas.com เมื่อ 9 พ.ย. 2569
